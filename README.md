# Mat Atlas

Interactive mind map of Brazilian Jiu-Jitsu — **274 skills**, **12 chains**, and a YouTube clip on every technique.

v2 is built around **step-in navigation**: you never stare at 274 nodes at once. Click a domain to drill in, Esc to step back, `/` to search. The camera pans, pinches, and flies without jank.

## Views

- **Map** — orbit of the current level (atlas → domain → family → techniques). Breadcrumbs, jump list, zoom/fit.
- **Chains** — twelve ordered sequences with a walk-on-map path.
- **Library** — searchable catalog with domain rail, bookmarks, and show-on-map.

Progress (unseen / training / solid) and bookmarks live in your browser.

## Keys

`/` search · `Esc` step back · `1/2/3` views · `←/→` siblings · `F` fit · `B` bookmark

## Run

```bash
npm install
npm run dev
```
